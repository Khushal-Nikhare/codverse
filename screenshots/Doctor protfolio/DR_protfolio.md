# 🦷 Teal Dental Clinic - Dr. Alisha Singh Portfolio

Welcome to the **Teal Dental Clinic** web application, a modern, full-stack patient management and clinic dashboard system designed for Dr. Alisha Singh. This project showcases a professional medical interface with both patient-facing and administrative features.

---

## 🌟 Key Features

### 📅 Patient-Facing Portal
- **Interactive Home Page**: A clean, teal-themed landing page with smooth animations and integrated contact options.
- **Seamless Booking**: Patients can schedule appointments directly through an intuitive booking form.
- **Medical Records Search**: A dedicated portal for patients to look up their treatment history using their ID.

### 🔐 Administrative Dashboard
- **Authentication**: Secure login for authorized medical staff.
- **Clinic Overview**: Real-time stats on total patients, daily appointments, and revenue trends.
- **Appointment Management**: Full CRUD operations for managing patient visitations, including filtering by status.
- **Patient Database**: Comprehensive records management with detailed treatment history and contact info.
- **Digital Prescriptions**: Generate and manage patient prescriptions electronically.
- **Advanced Analytics**: Data visualization using Recharts to track clinic performance, patient demographics, and financial growth.

---

## 🛠️ Technical Stack

- **Frontend**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Data Visualization**: [Recharts](https://recharts.org/)
- **State Management**: React Hooks & localStorage for persistence
- **Styling**: Vanilla CSS with a contemporary "Teal Medical" design system

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
1.  **Clone the repository**:
    ```bash
    git clone https://github.com/yourusername/doctor-portfolio.git
    cd doctor-portfolio
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Run the development server**:
    ```bash
    npm run dev
    ```
4.  **Access the application**:
    Open [http://localhost:5173/](http://localhost:5173/) in your browser.
