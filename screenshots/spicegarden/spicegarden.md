# SpiceGarden – Premium Indian Fusion Restaurant

SpiceGarden is a state-of-the-art, premium restaurant web application designed to offer an immersive digital experience of modern Indian fusion cuisine. Combining bold, traditional spices with contemporary culinary artistry, the platform provides a seamless journey from menu exploration to table reservation.

## ✨ Features

- **Dynamic Indian Fusion Menu**: Interactive and visually stunning menu showcasing signature dishes like Truffle Butter Chicken and Saffron Infused Sea Bass.
- **Advanced Reservation System**: Real-time table booking with multi-step validation and guest preference selection.
- **Admin Management Dashboard**: Comprehensive backend for managing:
    - **Reservations**: Track, confirm, or cancel bookings in real-time.
    - **Menu Management**: Update dishes, prices, and categories dynamically.
    - **Customer Inquiries**: Manage contact messages and feedback.
- **Real-time Cart System**: Seamlessly add dishes to a persistent cart for pre-ordering or delivery simulation.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop experiences.
- **Premium Aesthetics**: High-end visuals using CSS glassmorphism, smooth animations (AOS), and curated typography.

## 🛠️ Technology Stack

- **Frontend**: 
    - Semantic HTML5 & Vanilla CSS3
    - Modern JavaScript (ES6+)
    - **Design Patterns**: BEM, CSS Grid & Flexbox, Glassmorphism
    - **Libraries**: AOS (Animate on Scroll) for smooth transitions.
- **Backend (Simulation)**:
    - **Local Storage**: Used for data persistence in the demo to ensure zero-latency interactions.
    - **Admin Authentication**: Secure login portal for authorized personnel.
- **Assets**: 
    - Curated high-resolution photography from Unsplash.
    - Custom iconography and SVG elements.

## 🚀 Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/yourusername/spicegarden.git
    cd spicegarden
    ```
2.  **Open in Browser**:
    Simply open `index.html` in your favorite modern browser (Chrome, Firefox, Safari).

3.  **Access Admin Panel**:
    - Navigate to `admin/login.html`.
    - **Credentials**: `admin` / `spice123`
